# Qt Keyboard: что изменено

Доработка проекта «Грустная клавиатура» (Qt6, C++).

## Что сделано

Экранные кнопки теперь работают мышкой, а физическая клавиатура и мышка
используют один общий путь через сигналы и слоты.

### Как это работает

```
Мышка:        клик по кнопке ──► clicked ──► KeyBoard: emit key_clicked(текст) ──► окно дописывает текст в display
Физ. клавиша: keyPressEvent ──► animateClick() у нужной кнопки ──► дальше так же, как у мышки
```

Окно не знает, откуда пришёл сигнал: от мыши или от физической клавиши.

### Ключевые изменения по файлам

| Файл | Что изменено |
|---|---|
| `src/keyboard.hpp` | Добавлен `Q_OBJECT`, секция `signals:` с сигналами `key_clicked(const QString&)` и `backspace_clicked()`. Добавлен словарь `special_buttons` и методы `is_special_key`, `animate_special_button`. |
| `src/keyboard.cpp` | В `create_buttons` каждая кнопка (буквы, цифры, знаки) через `connect` отправляет `key_clicked` с текстом кнопки. «Удалить» отправляет `backspace_clicked`, пробел отправляет `key_clicked(" ")`. Эти две кнопки записаны в `special_buttons` по константам Qt (`Qt::Key_Backspace`, `Qt::Key_Space`). |
| `src/keyboard_window.cpp` | Два `connect`: на `key_clicked` (дописать текст в `display`) и на `backspace_clicked` (убрать последний символ через `QString::chop`). В `keyPressEvent` сначала проверяются специальные клавиши, затем остальные. Убрано прямое дописывание текста, чтобы буква не появлялась дважды. У `display` отключён фокус. |
| `src/keyboard_button.cpp` | Кнопкам отключён фокус (`Qt::NoFocus`), чтобы физический пробел не повторял последнюю нажатую мышкой кнопку. |
| `src/keyboard_data.cpp` | В `is_key_allowed` разрешены коды цифр, чтобы цифры работали с физической клавиатуры. |

### Исправленные ошибки

1. **Двойные буквы при нажатии физической клавиши.** Текст добавлялся напрямую и ещё раз через `animateClick` и сигнал. Оставлен только путь через сигнал.
2. **Физический пробел повторял последнюю букву после клика мышкой.** Кнопка с фокусом реагировала на пробел. Решение: `setFocusPolicy(Qt::NoFocus)` у кнопок.
3. **Физический Backspace не доходил до окна.** Строка `display` перехватывала его. Решение: `setFocusPolicy(Qt::NoFocus)` у `display`.
4. **Физические цифры не работали.** Их коды (48–57) отбрасывались проверкой `code < 65` в `is_key_allowed`.

## Что ещё не сделано

- Кнопка **Enter** (нет сигнала и поведения).
- **Окно приветствия** с кнопкой «Перейти к клавиатуре» и переход между окнами через сигналы и слоты.
- **Настроение Клавика** (картинка и текст).
- Кнопки Tab, Caps и Shift пока только нарисованы.
- Физические `-`, `=`, `.`, `\` не работают с клавиатуры (мышкой работают).

## Сборка

Запускать в терминале MSYS2 UCRT64 (или в обычном, если PATH настроен):

```
build.bat
build_ninja\keyboard.exe
```

Перед сборкой закрывай запущенную программу, иначе `keyboard.exe` не перезапишется.
